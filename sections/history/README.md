# History section

This folder owns the history and formulations chapter.

- `section.html` contains the complete `#history` section.
- `styles.css` contains the styles used only by that section.

The shortcake-and-coin image remains a root runtime asset because the generated page loads it directly. Do not edit `index.html` or `site.css` by hand; after changing this folder, run `node scripts/build-site.mjs` from the repository root.
